КАК ЗАЛИТЬ НА GITHUB PAGES
1. Создай репозиторий на github.com (Public).
2. Add file -> Upload files -> закинь index.html и play.html (распакованные из архива) -> Commit.
3. Settings -> Pages -> Source: Deploy from branch -> main / (root) -> Save.
4. Через минуту сайт будет на https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/
5. На телефоне открой ссылку -> меню браузера -> "Добавить на главный экран".

Игры (свои ромы) загружаются кнопкой "ДОБАВИТЬ ИГРЫ" внутри нужной системы; BIOS - последний пункт в карусели; телефон держи горизонтально внутри сайта и хранятся в браузере телефона.
Для PS1 загрузи свой BIOS (scph1001.bin) кнопкой BIOS.
Эмуляторы подгружаются с cdn.emulatorjs.org, нужен интернет.
